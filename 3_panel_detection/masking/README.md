# 빛가람동 태양광 마스킹 — 실행 및 작업 안내

네 명이 같은 원본 이미지 3,410장을 가지고 각자 맡은 파트를 작업하는 로컬 웹 도구입니다.
아래 명령은 모두 **프로젝트 최상위 폴더**에서 실행합니다.

## 1. 처음 준비하기

- **Python 3.10 이상**을 설치합니다.
- 공유받은 프로젝트 폴더를 준비합니다. ZIP으로 받았다면 압축을 먼저 풉니다.
- `3_panel_detection/masking/server.py`와 원본 이미지가 아래 위치에 있는지 확인합니다.

```text
KDN/
├─ 3_panel_detection/masking/
│  ├─ server.py
│  ├─ assignments.json
│  └─ web/
└─ data/
   ├─ bitgaram/
   │  └─ raw_tiles/
   │     └─ z19/
   │        ├─ 446760_207604.jpeg
   │        └─ ...                     # 원본 3,410장
   └─ solar_panel/
      └─ conf_0p1/                    # AI 예측을 보려면 필요
         ├─ summary.csv
         └─ masks/
            └─ ...png
```

`pip install` 등 추가 패키지 설치는 필요 없습니다. GPU나 인터넷 연결도 실행에 필요하지 않습니다.
AI 예측 파일이 없어도 직접 마스킹할 수 있습니다.

## 2. 실행하기

프로젝트 폴더에서 터미널을 엽니다. Windows에서는 파일 탐색기로 프로젝트 폴더를 연 뒤
마우스 오른쪽 버튼 메뉴의 **터미널에서 열기**를 사용하면 됩니다.

Python 버전을 확인합니다.

```bash
python --version
```

`Python 3.10` 이상이면 다음 명령을 실행합니다.

```bash
python 3_panel_detection/masking/server.py --open
```

Windows에서 `python` 명령이 동작하지 않으면 다음 명령을 사용합니다.

```powershell
py -3 3_panel_detection/masking/server.py --open
```

브라우저가 열리면 작업할 수 있습니다. 자동으로 열리지 않으면 주소창에 아래 주소를 입력합니다.

**http://127.0.0.1:8765**

작업하는 동안 서버를 실행한 **터미널을 열어 둡니다**. 작업을 마치면 화면에
**로컬 파일에 저장됨**이 표시되는지 확인하고, 터미널에서 **Ctrl+C**를 눌러 종료합니다.
다음 작업 때도 같은 명령으로 실행하면 됩니다.

### 원본 이미지가 다른 폴더에 있다면

`z19` 폴더의 실제 경로를 지정합니다. 공백이 있을 수 있으므로 경로를 따옴표로 감쌉니다.

```bash
python 3_panel_detection/masking/server.py --images "D:/shared/z19" --open
```

다른 경로의 원본을 사용하더라도 AI 예측을 보려면 프로젝트 안의
`data/solar_panel/conf_0p1/summary.csv`와 `masks/`를 함께 준비합니다.

## 3. 자기 파트 선택하기

네 사람이 서로 다른 파트를 하나씩 정한 뒤, 화면의 **1~4 버튼**으로 선택합니다.
작업자 이름이나 로그인은 필요 없습니다.

| 파트 | 이미지 수 |
| --- | ---: |
| 1 | 853장 |
| 2 | 853장 |
| 3 | 852장 |
| 4 | 852장 |

배정은 `3_panel_detection/masking/assignments.json`에 고정되어 있습니다. 이 파일은 수정하지 않습니다.
파트 안의 이미지는 무작위 순서로 표시되며, 새로고침해도 같은 순서가 유지됩니다.
선택한 파트와 마지막 이미지 위치는 같은 브라우저에 기억됩니다.

- **완료 개수·진행률:** ‘완료’와 ‘패널 없음’을 합친 값입니다.
- **보류 개수:** 판단을 미룬 이미지 수이며, 완료에 포함하지 않습니다.
- **하단 슬라이더:** 현재 이미지의 순서입니다. 드래그하면 다른 위치로 이동합니다.
  슬라이더 위치가 곧 완료 개수를 의미하는 것은 아닙니다.
- **미완료로 이동:** 아직 완료하지 않은 첫 이미지로 이동합니다.

## 4. 마스킹하기

### 사각형으로 그리기

1. **사각형**을 선택합니다.
2. 패널의 한 모서리를 누른 채 반대 대각선 모서리까지 드래그하고 놓습니다.
3. 생성된 사각형의 **네 꼭짓점을 드래그**해 실제 패널 경계에 맞춥니다.
4. 다른 영역도 필요하면 빈 곳에서 다시 드래그합니다.

기울어진 패널도 먼저 사각형을 만든 뒤 꼭짓점을 조정하면 됩니다.
드래그 중 **Esc**를 누르면 취소됩니다. 단순 클릭은 사각형을 만들지 않습니다.

### 다른 편집 기능

- **다각형:** 경계를 따라 점을 찍고 **E 또는 Enter**로 완성합니다. 타일 가장자리에서 잘린 패널 등에 사용합니다.
- **선택:** 영역 내부를 드래그해 이동하거나 꼭짓점을 조정합니다.
- **삭제:** 선택한 영역 하나를 지웁니다.
- **모두 지우기:** 현재 이미지의 모든 영역을 지웁니다. **Ctrl+Z**로 복구할 수 있습니다.
- **AI 예측:** 기존 AI 예측을 주황색으로 표시합니다. 직접 그린 영역은 초록색입니다.
  AI 예측은 참고용으로만 표시되며 정답 마스크에 자동으로 포함되지 않습니다.
- **내 영역:** 직접 그린 영역을 숨기거나 표시합니다. 숨겨도 삭제되지 않습니다.
- **화면 맞춤:** 사진 전체가 보이도록 확대율과 위치를 맞춥니다.
- **영역 · 메모:** 누르면 영역 목록과 작업 메모 입력란이 펼쳐집니다.

AI 예측은 `conf_0p1`에 저장된 confidence 0.1 이상 후보입니다. 틀린 예측도 포함될 수 있으므로
원본 사진을 보고 판단합니다. 예측이 0개인 경우와 파일이 없는 경우는 화면에 따로 표시됩니다.

### 작업 상태 지정

| 버튼 | 언제 누르나요? |
| --- | --- |
| **완료 · 다음** | 보이는 패널을 모두 마스킹했을 때 |
| **패널 없음 · 다음** | 사진을 확인했고 태양광 패널이 없을 때 |
| **보류** | 패널인지 판단하기 어렵거나 나중에 다시 확인해야 할 때 |

이 버튼을 누르면 상태를 저장하고 다음 이미지로 이동합니다. 패널이 없는 사진도 반드시
**패널 없음**으로 표시합니다. 영역이 그려져 있으면 먼저 지워야 ‘패널 없음’으로 지정할 수 있습니다.
완료한 영역을 수정하면 다시 ‘작업 중’이 되므로 수정 후 **완료 · 다음**을 누릅니다.

하단 보류 버튼 옆의 **결정 취소(T)**를 누르면 완료·패널 없음·보류·작업 중 상태를
**미작업**으로 되돌립니다. 다음 이미지로 넘어가지 않으며, 그린 영역과 메모는 보존됩니다.
완료·보류 집계에서도 빠지고 학습용 마스크 내보내기에서도 제외됩니다.
Ctrl+Z로 이전 상태를 복구할 수 있습니다. 영역까지 지우려면 **모두 지우기**를 별도로 사용합니다.

### 라벨링 기준

- 붙어 있는 패널 배열은 하나의 영역으로 그립니다.
- 패널 사이에 지붕이나 통로가 보이면 영역을 나눕니다.
- 주차장 태양광 캐노피도 포함합니다.
- 지붕·도로 등 패널이 아닌 부분은 제외합니다.
- 판단이 어려우면 메모를 남기고 보류합니다.

### 단축키

버튼 옆에도 단축키가 표시됩니다. 자주 쓰는 키는 왼손 주변에 모았습니다.

```text
  W 되돌리기   E 다각형 확정   R 완료
A 이전         S 보류          D 다음
                X 패널 없음
```

Enter와 Ctrl+Z도 계속 사용할 수 있습니다.

| 키 | 기능 |
| --- | --- |
| **Q / P / V** | 사각형 / 다각형 / 선택 |
| **W** | 마지막 점 되돌리기 (그리는 중이 아니면 작업 실행 취소) |
| **E 또는 Enter / Esc** | 다각형 확정 / 그리기 취소 |
| **Ctrl+Z / Ctrl+Shift+Z** | 실행 취소 / 다시 실행 |
| **Delete** | 선택 영역 삭제 |
| **마우스 휠** | 확대·축소 |
| **Space를 누른 채 드래그** | 사진 이동 |
| **F** | 화면 맞춤 |
| **A / D** | 이전 / 다음 이미지 |
| **S** | 보류 · 다음 |
| **R** | 완료 · 다음 |
| **X** | 패널 없음 · 다음 |
| **T** | 결정 취소 → 미작업으로 되돌리기 |

## 5. 저장하고 이어서 작업하기

완성한 영역과 수정 사항은 **자동 저장**됩니다. 완성하기 전의 다각형 점들은 아직 저장된
영역이 아니므로, 이동하거나 종료하기 전에 **Enter**로 완성하거나 **Esc**로 취소합니다.

작업 파일은 아래 폴더에 저장됩니다.

```text
data/bitgaram/annotations_v2/
├─ assignment.json
├─ part-1/
│  └─ 이미지ID.json
├─ part-2/
├─ part-3/
└─ part-4/
```

다음에 같은 프로젝트 폴더에서 서버를 실행하면 저장한 내용을 다시 불러옵니다.
다른 브라우저를 사용해도 작업 파일은 남아 있으며, 파트를 선택해 계속할 수 있습니다.

저장 실패 안내가 나오면 창을 닫지 말고 **저장 재시도**를 누릅니다. 여러 탭에서 같은 이미지를
수정해 충돌한 경우에는 **초안 내려받기**로 백업하고 **저장본 불러오기**로 최신 기록을 확인합니다.

작업 폴더는 Git에서 제외됩니다. **Git push로 작업 결과가 공유되지는 않습니다.**
백업하거나 다른 컴퓨터에서 이어 하려면 `annotations_v2` 폴더를 복사합니다.
한 저장 폴더를 여러 서버에서 동시에 사용하지 않습니다.

## 6. 결과 제출하기

상단 **결과 내보내기**를 누르면 선택한 파트의 `part-N.zip`이 내려받아집니다.
이 ZIP을 담당자에게 전달합니다. 중간 백업용으로도 내보낼 수 있습니다.

미완료나 보류 이미지가 있으면 개수를 안내합니다. ZIP에는 해당 이미지의 상태와 초안도
남지만, **학습용 마스크 PNG는 ‘완료’와 ‘패널 없음’ 이미지만 포함**합니다.

```text
part-N.zip
├─ manifest.json          # 이미지 목록과 상태
├─ annotations/           # 직접 그린 좌표·상태·메모
└─ masks/                 # 원본 크기 PNG, 배경 0 / 패널 255
```

## 7. 자주 생기는 문제

| 문제 | 해결 방법 |
| --- | --- |
| `python`을 찾을 수 없음 | Python 설치를 확인하고 Windows에서는 `py -3`로 실행합니다. |
| `3_panel_detection/masking/server.py`를 찾을 수 없음 | 터미널이 `3_panel_detection` 폴더가 들어 있는 프로젝트 최상위 폴더인지 확인합니다. |
| 원본 이미지가 없다는 메시지 | 원본 3,410장이 있는지 확인하거나 `--images`로 `z19` 경로를 지정합니다. |
| 주소에 접속되지 않음 | 서버를 실행한 터미널이 열려 있고 오류 없이 실행 중인지 확인합니다. |
| 포트가 이미 사용 중 | 이미 실행한 서버를 쓰거나 `python 3_panel_detection/masking/server.py --port 8766 --open`으로 실행합니다. |
| AI 예측이 표시되지 않음 | `AI 예측`을 체크하고 `conf_0p1/summary.csv`와 `masks/`가 있는지 확인합니다. |
| 사진이 너무 확대되거나 위치가 어긋남 | **화면 맞춤(F)**을 누릅니다. |
| 업데이트한 화면이 반영되지 않음 | 작업 저장을 확인한 뒤 브라우저를 새로고침합니다. |

## 담당자용: 네 파트 수합하기

네 사람이 제출한 ZIP을 프로젝트 최상위 폴더에 놓고 실행합니다.

```bash
python 3_panel_detection/masking/merge.py part-1.zip part-2.zip part-3.zip part-4.zip
```

완료하지 않은 이미지가 있으면 수합을 중단하도록 하려면:

```bash
python 3_panel_detection/masking/merge.py part-1.zip part-2.zip part-3.zip part-4.zip --require-complete
```

기본 결과 폴더는 `data/bitgaram/annotations_merged`입니다. `report.json`에 완료 수와
미완료 이미지 목록이 기록됩니다. 파트·이미지 누락과 중복, 배정표 차이, 잘못된 좌표,
마스크 크기와 내용 불일치를 검사하며 기존 결과를 덮어쓰지 않습니다.
다시 수합할 때는 새로운 출력 폴더를 지정합니다.

```bash
python 3_panel_detection/masking/merge.py part-1.zip part-2.zip part-3.zip part-4.zip --output data/bitgaram/annotations_merged/round-2
```
