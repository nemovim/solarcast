# 사전 추론 모듈

`imagery/`는 VWorld z19 영상과 건물 외곽선 조회, 픽셀 좌표 변환을 담당한다. `panel/`은 NLR 패널 모델의 학습과 추론을, `roof/`는 SAM을 이용한 옥상 분할을 담당한다. 이 모듈은 웹이나 이전 Python 백엔드에 의존하지 않는다.

`pipelines/precompute.py`가 패널과 옥상 사전 추론을 차례로 실행해 모델별 GeoJSON과 처리 완료 목록을 생성한다. 웹은 이 결과를 읽으며 면적·그림자·발전량은 `frontend/`에서 계산한다. 이전 실시간 백엔드와 건축물대장·옥상 연구 코드는 `legacy/`에 보존한다.
