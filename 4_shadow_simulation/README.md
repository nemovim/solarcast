# 4. 3D 그림자 및 발전량 계산 시뮬레이션 모듈 (Shadow Simulation)

태양 궤적 알고리즘과 건물 높이를 결합하여 3D 그림자 투영을 수행하고, 시간대별 패널 음영률 및 NASA POWER 일사량 기반 연간 발전량을 사전 계산하는 시뮬레이션 엔진입니다.

---

### 주요 알고리즘 및 구성

1. **`shadow-core.js` (시뮬레이션 코어 엔진)**:
   - **태양 위치 계산**: `SunCalc` 라이브러리를 기반으로 특정 날짜/시간의 태양 고도(Altitude) 및 방위각(Azimuth) 정밀 산출
   - **3D 그림자 투영**: 건물 층고(`gro_flo_co × 3.3m`)에 따라 햇빛 반대 방향으로 옥상 그림자 폴리곤 생성
   - **음영 판정 (`shadeOn` / `shadowAt`)**: 태양광 패널 및 옥상 모듈이 인접 건물의 그림자에 가려지는 비율을 기하학적 교집합으로 판정
2. **`precompute_day.mjs` (배치 계산기)**:
   - 나주시 빛가람동 전역 2,207동 건물과 1,000+개 태양광 패널에 대해 하루치(5분 간격) 그림자 및 1년치 일조율을 멀티스레드로 사전 계산
   - **NASA POWER 월별 수평면 전천 일사 기후값**(연 1,410 kWh/㎡)과 Haurwitz 청천 일사 프로파일을 적용하여 연간 총 발전량(MWh/yr) 도출
3. **`output/11-11.json`**:
   - 시연 및 발표일(11-11) 전역 사전 계산 결과 데이터
    - 기존 웹 시연용 연구 산출물이다. 현재 `5_web_service`의 Task 1 화면 시안은 이 파일을 읽지 않는다.

---

### 실행 방법

```bash
cd 4_shadow_simulation
npm install

# 특정 날짜(예: 11-11) 4스레드 전역 시뮬레이션 실행
node precompute_day.mjs 11-11 4
# 또는
npm run precompute
```
